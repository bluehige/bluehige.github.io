# 타입메이트 · MBTI 페르소나 파일럿

MBTI를 직접 고르고 **기획 · 대화 · 개발** 중 목적을 선택해 AI 페르소나 프롬프트를 받는 정적 웹 파일럿입니다.

**사용 주소:** https://bluehige.github.io/mbti-persona/

## 제공 기능

- MBTI 16유형 직접 선택. 검사 문항은 없습니다.
- 16유형 × 3목적 = 48개의 원본 한국어 추천.
- 추천 역할, 응답 스타일, 구체적인 응답 지침과 답변 구성.
- 프롬프트 직접 편집, 원문 복원, 클립보드 복사, UTF-8 텍스트 저장.
- 선택적으로 입력한 요청은 복사·텍스트 저장 시 프롬프트 뒤에 함께 붙습니다.
- 유형과 목적을 담은 선택 링크. 개인 입력과 편집 내용은 공유 링크에 포함하지 않습니다.
- 모바일 반응형 화면과 키보드 조작. 목적 탭은 좌우 방향키와 Home/End를 지원합니다.

## 동작 방식

AI API나 서버를 호출하지 않습니다. 고정된 추천 데이터에서 선택한 유형·목적에 맞는 프롬프트를 조합합니다. 복사한 문구는 사용하는 AI의 대화창에 붙여 넣어 사용합니다.

이 콘텐츠는 MBTI를 시작점으로 제안한 응답 스타일입니다. 실제 성격을 검사하거나 추천 효과를 검증한 심리검사 결과가 아닙니다. 사용자가 직접 밝힌 선호와 작업 요청이 추천보다 우선하도록 프롬프트에 명시했습니다.

마지막으로 고른 유형·목적만 브라우저 localStorage에 저장합니다. 편집한 프롬프트는 현재 화면을 열어 둔 동안 조합별로 유지되며 새로고침하면 초기화됩니다. 입력한 요청은 서버로 전송하거나 저장하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 선택·추천·편집 화면 |
| `styles.css` | 데스크톱·모바일 스타일 |
| `personas.js` | 16유형의 48개 추천 콘텐츠 |
| `app.js` | 프롬프트 조합, 선택 상태, 편집·복사·저장 |

## 로컬 실행

이 폴더에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 빌드나 패키지 설치는 필요 없습니다. 클립보드 자동 복사는 HTTPS 또는 localhost 환경에서 권장하며, 지원하지 않는 브라우저에서는 호환 복사를 시도합니다.

## 콘텐츠 수정

`personas.js`의 `PERSONAS[유형].modes[목적]`을 수정합니다.

- 목적 키: `planning`, `conversation`, `development`.
- `title`: 추천 AI 역할 이름.
- `pitch`: 추천 역할의 설명.
- `rules`: 실제 응답에 반영할 구체적인 지침.
- `format`: 답변의 구성.

유형 전체에 적용되는 기본 원칙은 `app.js`의 `buildPersonaPrompt`에서 관리합니다.
