# 푸른 수염 스튜디오 (Blue Hige Studio)

게임, 앱, 360° 이미지, Blender 및 AI 제작 도구를 소개하는 정적 GitHub Pages 홈페이지입니다.

**홈페이지:** https://bluehige.github.io/

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| index.html | 스튜디오 소개, 대표 프로젝트, 검색 가능한 작품 목록 |
| project.html / project.js | 같은 데이터로 구성하는 프로젝트 상세 및 스크린샷 확대 |
| projects.js | 프로젝트의 ID, 이름, 상태, 설명, 기능, 링크, 표시용 문구와 이미지 매핑 |
| app.js | 공용 카드 렌더러, 분류·검색, 선택 상태 유지, 대표작 전환 |
| styles.css | PC 3열 / 태블릿 2열 / 휴대폰 1열 반응형 스타일 |
| assets/images/ | 제공된 디자인 리소스를 변환한 WebP 이미지 |

## 2026-10-22 디자인 개선

- 푸른 수염 캐릭터를 메인 화면과 헤더·푸터에 적용했습니다.
- 프로젝트 10개에 제공된 16:9 소개 일러스트를 적용했습니다. 별도 그림이 없는 GamePlanner, Game UI/UX Skill, VoiceGuard는 HTML/CSS 그래픽을 사용합니다.
- 대표 프로젝트의 설명과 이미지를 나눠 글자가 이미지 위에 겹치지 않게 했습니다.
- 카드 본문은 15–15.5px, 상세 본문은 16–17px로 조정하고 글자 명암과 줄간격을 높였습니다.
- 분류별 개수, 검색 결과 수, 검색·분류 초기화를 제공합니다. 현재 탭에서 상세 페이지를 다녀와도 선택한 분류와 검색어가 유지됩니다.
- 스크린샷 확대는 브라우저 기본 dialog를 사용합니다. Escape, 닫기 버튼, 바깥 영역 클릭으로 닫을 수 있습니다.
- 이미지 23개(480/960px 썸네일, 1440px 마왕성 아트, 캐릭터 2종)의 총 용량은 1,578,370 bytes입니다. 반응형 srcset과 지연 로딩으로 필요한 크기를 선택합니다.
- 기존 13개 프로젝트의 ID·상태·상세 설명·외부 링크와 실제 게임 스크린샷을 유지합니다.

## 프로젝트 관리

projects.js의 BH_PROJECTS 배열이 제품 정보의 기준입니다. 하단 display 설정은 짧은 카드 설명과 표시용 이미지를 덧붙입니다. 새 프로젝트를 추가할 때는 고유 ID와 category(game/app/tool/lab), 상태, 설명, 기능, 링크를 설정하세요. 프로젝트 수와 카테고리 수는 자동 계산됩니다.

상세 페이지는 project.html?id=프로젝트ID 형태이며 프로젝트마다 HTML을 만들 필요가 없습니다.

소개 일러스트는 실제 실행 화면으로 표시하지 않습니다. 실제 화면은 gallery 배열에 넣으세요. 제공된 전체 홈페이지 시안 두 장은 참고용이며 페이지 자체를 이미지로 붙이지 않았습니다.

## 검증

JavaScript 구문, 13개 ID 및 이미지 참조, PC·휴대폰·태블릿 화면, 검색과 분류, 빈 결과 초기화, 상세 복귀, 대표작 전환, 스크린샷 확대 및 Escape 포커스 복귀를 확인합니다.

순수 HTML/CSS/JavaScript이므로 패키지 설치나 별도 빌드 과정이 없습니다. 저장소 루트에서 정적 서버를 열면 됩니다. 폰트와 기존 실제 게임 스크린샷에는 인터넷 연결이 필요하며 폰트는 시스템 글꼴로 대체됩니다.

기존 mbti-persona/, .nojekyll, app-ads.txt, PROFILE_README.md는 홈페이지 디자인 작업과 별도로 유지합니다.
