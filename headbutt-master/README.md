# 박치기 마스터 키우기 — v0.2.0

모바일 세로형 1:1 박치기 대회 파일럿. 기존 다수의 적 생존 전투를 AI 상대 한 명과의 결투로 변경했습니다.

## 실행

https://bluehige.github.io/headbutt-master/?v=0.2.0

외부 게임 엔진, CDN, 이미지 다운로드 없이 HTML/CSS/Canvas/JavaScript로 실행합니다. 로컬 확인은 이 폴더에서 정적 HTTP 서버를 실행하면 됩니다.

## 게임 흐름

- 동대회 → 구대회 → 시대회 → 지역대회 → 전국대회 → 아시아대회 → 세계대회 → Headbutt Championship.
- 각 대회는 1:1 10연전. Lv.1에 첫 기술을 받고, 승리 후 다음 회전 진출 시 레벨이 올라 Lv.10에 10개 기술을 습득합니다.
- 배운 기술 중 네 개를 장착합니다. 경기 전 또는 일시정지 중 비급 교체가 가능합니다.
- 기본 공격: 짧게 눌러 기본 박치기, 길게 눌러 차지. 0.72~0.96초 구간에서 놓으면 PERFECT 배율.
- 이동으로 거리를 조절하고 회피 또는 반격으로 상대 공격 예고에 대응합니다.
- 한 경기 60초. 상대 체력이 0이 되면 승리. 시간 종료 시 남은 체력 비율 비교, 동률은 플레이어 패배.
- 승리 후 다음 회전에서 최대 체력의 32% + 10 회복, 기력 완충.
- 대회 우승 시 다음 대회와 복장·체형 단계가 열립니다.
- 새 대회 출전 시 경기 레벨과 습득 기술은 초기화됩니다. 부위 강화와 재화는 영구 유지됩니다.
- 기술 연습장은 10개 기술을 바로 사용할 수 있으며 보상·우승·승패 기록을 변경하지 않습니다.

## 기술

사용자가 지정한 기술의 명칭과 역할을 유지했습니다.

| 레벨 | 기술 | 동작 |
|---|---|---|
| 1 | 더블 박치기 | 85% 피해 × 2회 |
| 2 | 이환이형 박치기 | 1초 회피, 상대 뒤로 이동, 140% 피해 |
| 3 | 강화 박치기 | 준비 동작 후 250% 피해 |
| 4 | 손으로 잡고 박치기 | 잡기·기절 후 방어 관통 65% × 3회 |
| 5 | 원거리 박치기 | 이마 탄환을 발사해 165% 피해 |
| 6 | 반격 박치기 | 1.5초 동안 첫 피격을 막고 220% 반격 |
| 7 | 불도저 박치기 | 접근·돌진, 200% 피해, 밀치기 |
| 8 | 뇌진탕 박치기 | 150% 피해, 1.7초 기절 |
| 9 | 금강불괴 이마 | 4초 동안 받는 피해 55% 감소 |
| 10 | 박치기 왕의 일격 | 준비 동작 후 500% 피해 |

6~10번은 파일럿을 완성하기 위해 추가한 제안이며 UI에도 추가 제안으로 구분했습니다. 밸런스는 초안입니다.

## 조작

모바일: ◀/▶ 이동, 회피 버튼, 박치기 버튼 누르기/떼기, 네 개의 보라색 기술 버튼.
PC: 좌우 방향키 이동, Space 누르기/떼기 박치기, D 회피, 1~4 장착 기술, Esc 일시정지.
화면 전환·창 포커스 이탈 시 자동 일시정지. 포인터 취소와 화면 크기 변경 시 입력을 초기화합니다.

## 기존 저장 데이터

새 키: `headbutt_master_pilot_v2`. 이전 `headbutt_master_pilot_v1`의 골드, 주문서, 네 부위 강화, 우승 여부·횟수, 기존 최고 기록과 패키지 수령 여부를 이관합니다. 이전 키는 삭제하지 않습니다. 신규 1:1 승패는 별도로 누적합니다. 경기 중 상태의 재시작 복원은 제공하지 않습니다.

## 파일 구조

- `engine.js`: 순수 전투 규칙, 기술, 레벨 전환, 보상, 저장 스키마.
- `art.js`: 코믹 캐릭터, 허리 회전, 링·관중·조명 Canvas 렌더링.
- `game.js`: 화면 전환, 입력, 네 슬롯 장착, 전투 UI, 오디오, 결과 창.
- `styles.css`, `index.html`: 모바일 반응형 화면.

## 검증 범위 (2026-10-22)

- Node 전투·저장 로직 회귀 테스트 37/37 통과.
- Chromium 브라우저 UI 동작 및 레이아웃 테스트 25/25 통과, JavaScript 런타임 오류 0건.
- 화면 크기: 320×568, 360×740, 390×844, 430×932, 1280×900.
- 더블 타격, 뒤 회피, 강화 준비 동작, 잡기 연타, 이마 탄환, 반격, 기절, 방어, 궁극기, 기력/재사용 제한, 기술 교체, 10연전 전환, 우승 보상, 기존 데이터 이관을 확인했습니다.
- 화면 테스트는 로컬 파일을 인라인으로 주입한 Chromium 환경이며 저장소는 테스트 대역을 사용했습니다. 실제 휴대폰, Safari, 배포 도메인의 localStorage는 검증했다고 주장하지 않습니다.
- `?test=1` 디버그 접근은 localhost/127.0.0.1에서만 노출됩니다.

온라인 PvP·통합 랭킹·실제 결제·광고는 구현 범위에 포함되지 않습니다. 상점의 3,300원 상품은 무료 1회 가상 시연입니다.
